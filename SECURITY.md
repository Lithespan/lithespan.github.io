# Security policy

Report a suspected vulnerability or release-integrity problem to [contact@lithespan.com](mailto:contact@lithespan.com?subject=Security%20report).

Include the affected repository or release reference, operating system, architecture, and enough information to reproduce or assess the issue. Do not include customer data, credentials, exploit material, or other sensitive information in the initial message.

Public issue support is best effort. Contractual response times and incident obligations apply only under an explicit support agreement.
